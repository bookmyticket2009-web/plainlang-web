Everything you need, in English

    
Readable by anyone, powerful enough for real scripts.

    

      
Zero-Quotes Syntax
Write natural text and variables (Print Hello name from city) without string delimiters or semicolons.

      
PlainLang Studio IDE
Built-in desktop editor with live variable and object inspection, syntax highlighting, and one-click .exe compilation.

      
Full Control Flow & Functions
If / Else if / Else, While, Repeat, For each, Define / Do / Return, and Try / Catch error handling.

      
Lists, Objects & JSON
Native list manipulation, dot-notation dictionaries (user.name), Parse json, and To json.

      
Dynamic Python Built-ins
Access 70+ Python built-in functions in plain English (Call len with nums into count, Convert 255 to hex into hex_val).

      
Standalone Installer & CLI
Installs to C:\Program Files\PlainLang, registers .plain double-click execution, and runs from any terminal via plainlang.exe.

Installation & CLI Guide

    
Windows users get a one-file installer. Developers can build from source with PyInstaller.

    

      

        
Option A: Windows installer

        
    
          
  1. Download PlainLang-Setup-2.0.0-x64.exe from the latest release.
    2. 
          
  2. Run the installer. It installs to C:\Program Files\PlainLang, adds plainlang.exe to System PATH, and associates .plain files.
    3. 
          
  3. Double-click any .plain file to run it, or open a terminal and run the CLI below.
    4. 
        

        
plainlang.exe script.plain

      

      

        
Option B: Build from source

        
    
          
  1. Clone the repository and move into the project folder.
    2. 
          
  2. Install PyInstaller with pip install pyinstaller.
    3. 
          
  3. Build the single-file executable.
    4. 
        

        
git clone https://github.com/bookmyticket2009-web/plainlang

        
python -m PyInstaller --onefile --clean --noconfirm --name plainlang plainlang.py
